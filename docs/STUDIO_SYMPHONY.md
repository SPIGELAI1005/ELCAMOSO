# Studio Symphony (Studio 2.0)

Studio modes: **Sound** · **Symphony** · **Fusion**.

Not a DAW. Six arrangement dials modify musical rules — not raw stem faders (unless Advanced).

## Symphony dials

| Control   | Left ↔ Right           |
| --------- | ---------------------- |
| Energy    | Calm ↔ Intense         |
| Build     | Slow ↔ Fast            |
| Rhythm    | Loose ↔ Driving        |
| Melody    | Subtle ↔ Expressive    |
| Drama     | Minimal ↔ Cinematic    |
| Variation | Predictable ↔ Evolving |

Instrument focus toggles always keep a viable base (atmosphere).

Demo drives: Gentle / City / Highway / Energetic — same trace + seed for A/B.

## Fusion

Machine + Symphony + balance. Advanced: machine presence, music energy, shift emphasis, harmonic resonance.

## Describe

Keyword (and optional AI) → Studio parameters. Never drive telemetry. Not generative music.

## Save

Experience Presets → Garage (`experiencePresets` + Fusion saves).

Modules: `src/lib/studio/`, panels under `src/components/studio/`.
