# Drive DNA

Drive DNA is a **musical motion signature**, not a driver score.

## Dimensions (0–100)

| Dimension     | Meaning                                                |
| ------------- | ------------------------------------------------------ |
| **Energy**    | How strongly the journey built and released intensity. |
| **Flow**      | How continuously motion evolved.                       |
| **Rhythm**    | How recurring acceleration / cruise patterns appeared. |
| **Variation** | How much motion state changed.                         |
| **Regen**     | How much deceleration shaped the motion.               |

## Archetypes (descriptive, non-judgmental)

Examples: Progressive Cruiser, Pulse Rider, Smooth Builder, Dynamic Flow, Night Rhythm, Quiet Glide, Open Pulse.

Never: good / bad / safe / unsafe / aggressive.

## Source

Computed from the Journey `energyTimeline` plus aggregate throttle/regen shares and duration — never from map geometry.
